Files:
  arm.glb      — right-arm region (bones + biceps/triceps), selectable/animated
  skeleton.glb — whole-body skeleton context (all bones except the right
                 humerus/radius/ulna, which arm.glb provides). Built by
                 scripts/build_skeleton.py using the same transform as the arm,
                 decimated (meshoptimizer) and meshopt-compressed.

Source parts used (right arm), by FMA id:
  bone_humerus   : FMA23130
  bone_radius    : FMA23464
  bone_ulna      : FMA23467
  muscle_biceps  : FMA37684 + FMA37686 (short + long head)
  muscle_triceps : FMA37695 + FMA37697 + FMA37699 (medial + lateral + long head)

Modifications:
  Parts merged into five named meshes; reoriented upright with the elbow at the
  origin; recentred and uniformly scaled; decimated (meshoptimizer) and
  re-exported as glTF/GLB. See scripts/build_arm_model.py.
